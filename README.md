# Riverside railway simulator

[Play the game](https://deprasny.github.io/warehouse-3d-playground-pages/#/game).

This repository contains the published static build only. Source development stays in a private repository. GitHub Pages publishes the `docs/` folder from `main` after a verified build is pushed here.

Asset attribution is included with the models and on the [audio credits page](https://deprasny.github.io/warehouse-3d-playground-pages/audio/credits.html).
