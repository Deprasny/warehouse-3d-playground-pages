CC206 V12 — original Blender reconstruction for Depras

Model: Depras / Codex, original V12 reconstruction from photographic references.
Game derivatives: selective geometry reduction, rigid wheel/bogie/door anchors,
vertex-color Standard PBR batching and Meshopt compression.
No Sketchfab geometry is incorporated in these V12 GLBs. The separately retained
cc206-sketchfab-* files have their own author and licence credits.
This file records provenance; it does not assign a new licence to the original model.
